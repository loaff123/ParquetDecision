# Preserved original comparison evidence

These two JSON files retain all 40 original method/case outcomes across ten original synthetic workloads. They are feasibility records from the earlier throwaway investigation, not production verifier certificates. The explicit-schema Arrow baseline matches all eight successful cases and safely refuses the same two other cases. No conversion, speed, scientific-validity, market-gap or adoption advantage is established.

The original prototype verifier did not check all synthesized columns and loaded whole files. Its successful rows below are not complete correctness guarantees. The production independent-verification and resource gates must be assessed separately. All methods share the PyArrow ecosystem in the original value-checking path; this is not an independent-decoder oracle.

Only filenames were changed for a public-facing presentation. JSON bytes are unchanged from the internally preserved final original records. summary.json is a derived index, not a new experiment. Exact original first-run records, original filenames, code and review evidence remain in the private review packet. These records contain no private development paths.
